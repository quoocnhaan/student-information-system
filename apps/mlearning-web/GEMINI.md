# Project Rules

## Technology
- React
- TypeScript
- Vite
- CSS Modules
- React Router
- Lucide React

## Rules
- Use TypeScript only.
- Do not use JavaScript.
- Do not use TailwindCSS.
- Use CSS Modules for styling.
- Do not delete files unless explicitly requested.
- Do not reset or discard existing user changes.
- Do not overwrite unrelated code.
- Do not rewrite unrelated components.
- Check existing components before creating new ones.
- Check existing TypeScript types and interfaces before modifying components.
- Check imports and exports after modifications.
- Preserve the existing project architecture and UI unless the user explicitly requests a redesign.

## Important
This project currently contains many uncommitted changes.
Never discard, reset, restore, or overwrite existing user changes unless explicitly requested.

Before making changes, inspect the existing code and understand how the relevant components work.
